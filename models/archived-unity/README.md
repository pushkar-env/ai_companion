# Archived Unity character imports

Owner requested keeping only Alita on 2026-10-04. Original (CC5Inspection), Cosmos,
the original diagnostic materials, former roster tools and pre-change scene copies
are preserved here with their .meta GUIDs, outside Unity Assets. They are not loaded
or included in the current app. Original exports elsewhere in models are unchanged.

The active TalkingCompanion and CCCharacterTest scenes now use Alita and preserve their
own original scene GUIDs. Do not move the historical scene copies into Assets alongside
the active scenes: they intentionally retain the same GUIDs for recovery. Restore an
archived model and its .meta together only if it is deliberately needed again.
